## 1. Architectural Philosophy

Traditional career platforms operate on direct matching:
$$\text{Candidate} \longrightarrow \text{Job}$$
This model fails because it ignores the path required to become qualified. A candidate missing key prerequisites is either rejected by employers or recommended courses detached from actual opportunities.

SkillRoute models career mobility as a **constrained graph optimization problem**:
$$\text{Current Capability} \longrightarrow \text{Capability Map} \longrightarrow \text{Transferable Graph} \longrightarrow \text{Target Opportunity} \longrightarrow \text{Missing Prerequisites} \longrightarrow \text{Optimized Pathway} \longrightarrow \text{Evidence} \longrightarrow \text{Outcome}$$

```
                                    SKILLROUTE DATA FLOW
┌───────────────────────┐
│     USER PROFILE      │ (Resume / Skills / Projects)
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│ NLP SKILL EXTRACTION  │ (Explicit vs Evidence-Backed vs Inferred)
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│  SKILL NORMALIZATION  │ (ESCO 1.2.1 & O*NET 31.0 Canonical Alignment)
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│   CAPABILITY GRAPH    │ (Directed Prerequisite & Transferability Edges)
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│  TRANSITION ANALYSIS  │ (Score = Fit + Demand + Transfer - Cost - Gap)
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│   PATH OPTIMIZATION   │ (argmax [Gain / Cost] subject to Time Budget)
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│     EVIDENCE PLAN     │ (Learn → Build → Prove → Apply)
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│   OUTCOME FEEDBACK    │ (Applications, Interviews, Offers → Edge Weight Retraining)
└───────────────────────┘
```

## 3. Verified Foundation Sources (No Invented Data)

1. **ESCO v1.2.1 (European Skills/Competences, Qualifications and Occupations):** Official taxonomic hierarchy and skill relationships.
2. **O*NET 31.0 Database:** Transferable skills, work activity descriptors, and task requirements.
3. **National Career Service (NCS) India:** Official Government of India platform context for regional demand indicators.
4. **WEF Future of Jobs 2025:** Macro skill transformation signals across high-growth domains.
5. **PLFS & AISHE:** Indian regional statistics contextualizing workforce supply and educational attainment.

---

## 4. Responsible AI & Safety Principles

1. **Structured Engine First:** Decisions are generated by the mathematical decision model; LLMs provide human-readable explanations.
2. **Evidence Separation:** Skills are strictly categorized into Explicit, Evidence-Backed, and Inferred to avoid false positive assumptions.
3. **Transparent Uncertainty:** The UI surfaces confidence levels and data freshness rather than asserting absolute certainty.
4. **No Guarantees:** Clear disclaimers communicate that recommendations represent evidence-based estimates under stated constraints.
